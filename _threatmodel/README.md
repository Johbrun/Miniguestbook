# Modèle de menaces — Phase 1

Ce dossier contient le **threat model de départ**, à compléter par les étudiants.

- [`threat-model.json`](threat-model.json) — modèle **OWASP Threat Dragon** (à ouvrir avec
  [Threat Dragon](https://owasp.org/www-project-threat-dragon/), desktop ou web). Il contient un DFD
  amorcé et quelques menaces STRIDE d'exemple. **À enrichir.**
- [`dfd.md`](dfd.md) — diagramme de flux de données (version texte) + actifs.
- [`cidt.md`](cidt.md) — gabarit d'analyse **CIDT** (Confidentialité, Intégrité, Disponibilité,
  Traçabilité) par actif.
- [`stride.md`](stride.md) — gabarit d'analyse **STRIDE** par composant.

> Le modèle est versionné (threat-model-as-code) : commitez vos évolutions, elles sont reviewables en PR.
